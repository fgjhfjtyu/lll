# VoltPro — دستیار محاسبات برق برای اندروید

اپلیکیشن بومی اندروید با رابط فارسی، پردازش آفلاین و Workflow آماده GitHub Actions برای ساخت APK.

## امکانات نسخه 1.0.0

- قانون اهم: محاسبه ولتاژ، جریان یا مقاومت با داشتن دو مقدار
- محاسبه جریان بار تک‌فاز و سه‌فاز با ضریب توان و بازده
- توان اکتیو، ظاهری و راکتیو سه‌فاز
- افت ولتاژ کابل با انتخاب تک‌فاز/سه‌فاز و مس/آلومینیوم
- پیشنهاد اولیه سطح مقطع کابل براساس افت ولتاژ مجاز
- مقاومت معادل سری و موازی
- محاسبه kVAr بانک خازنی برای اصلاح ضریب توان
- ظرفیت ظاهری ترانسفورماتور
- سرعت سنکرون موتور و لغزش
- انرژی مصرفی و هزینه تخمینی
- ولتاژ سیم‌پیچ در اتصال ستاره و مثلث

## ساخت APK در GitHub

1. فایل ZIP را استخراج کنید.
2. تمام محتویات پوشه `VoltPro-Android` را در ریشه یک مخزن جدید GitHub قرار دهید.
3. تغییرات را با شاخه `main` ذخیره و Push کنید.
4. در GitHub وارد زبانه **Actions** شوید.
5. Workflow با نام **Build VoltPro Android APK** را باز کنید.
6. در صورت نیاز روی **Run workflow** بزنید. با هر Push به `main` یا `master` نیز خودکار اجرا می‌شود.
7. پس از سبزشدن اجرا، در پایین صفحه بخش **Artifacts** را باز کنید و `VoltPro-Android-APK` را دانلود کنید.
8. ZIP دانلودشده را استخراج کنید؛ فایل نصب برنامه `VoltPro-debug.apk` است.

## مشخصات

- Kotlin و Android SDK
- حداقل Android 6.0 (API 23)
- استفاده از محاسبات به‌صورت کاملاً آفلاین
- بدون نیاز به API، حساب پولی یا کتابخانه جانبی
- APK خروجی فعلی از نوع Debug و مناسب آزمایش است.

## نکات مهم مهندسی

افت ولتاژ و پیشنهاد سطح مقطع کابل در این نسخه برآورد اولیه با مدل مقاومتی هادی هستند؛ راکتانس کابل در مدل منظور نشده است. انتخاب نهایی کابل باید بر اساس جریان مجاز، جنس و نوع عایق، دمای محیط، روش نصب، گروه‌بندی، طول مسیر، افت ولتاژ مجاز، جریان اتصال کوتاه و هماهنگی حفاظت‌ها کنترل شود. محاسبات اصلاح ضریب توان نیز جایگزین بررسی هارمونیک‌ها، رزونانس، جریان هجومی و طراحی پله‌های بانک خازنی نیستند. اتصال ستاره/مثلث باید با پلاک موتور و ولتاژ نامی هر سیم‌پیچ تطبیق داده شود.
